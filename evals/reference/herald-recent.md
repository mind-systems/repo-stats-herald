Herald довёл релизный путь до конца — от определения того, что в релиз вошло, до его публикации на GitHub и уведомления с номером версии.

- **Окно «с последнего деплоя»** — заметка охватывает всё, что накопилось с предыдущего деплоя в это окружение, а не фиксированный календарный период. Вынесено отдельным модулем и закрыто тестами.
- **Заметка как отчёт** — релизная заметка собирается общим движком отчётов, а не собственным параллельным механизмом.
- **Публикация релиза** — на push в релизную ветку создаётся релиз на GitHub с текстом заметки, а сообщение в Telegram получает заголовок с версией. Добавлен клиент GitHub Releases; проводка прошла через приём событий, доставку и корень приложения.
