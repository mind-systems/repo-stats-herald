### Ground-truth checks (re-verified this round)
- **First-parent walk format** — `git rev-list --reverse --first-parent --parents --end-of-options HEAD` emits the root line as a single token (commit, no parent) and every later line as `<commit> <first-parent>`. The plan's "`before` = first parent when present, else the empty-tree SHA" reduction holds; the root uniformly becomes `resolve(bare, 4b825dc…, root)`.
- **Empty-tree root range** — `git log <empty-tree>..<root>` lists the root commit at exit 0, so the collector's `git log before..after` (with `--numstat --shortstat`) succeeds for the root step; `git show <empty-tree>:<path>` fatals → `LinkedChangeResolver._read_roadmap_at` (uses `check=False`) reads it as "no prior roadmap".
- **Unknown/unborn ref** — `git rev-list … <unknown>` exits non-zero (`fatal: ambiguous argument …`), so Task 1's `check=False` + `return []` correctly yields the empty-steps safety net instead of raising.
- **Idempotency by recorded SHA** — For any first-parent step `(before, after)`, `git log before..after` always includes `after`, so `after` lands in that entry's `commit_shas`; the recorded-SHA union therefore covers prior backfill runs and live 4.3 pushes alike, and adding only `after` to the local `recorded` set per step is sufficient because the first-parent line partitions commits into disjoint step ranges (no commit is an `after` of two steps). Merge side-branch commits are never first-parent tips, so they never appear as an `after` and cannot double-cover.
- **Writer / wiring parity** — `content = "\n".join([*completed_tasks, *messages])`, `commit_shas = tuple(c.sha …)`, `changed_at = collector.commit_timestamp(bare, after)`, `[embedding] = await embedder.embed([content])`, and the full `EpisodicEntry` construction mirror `src/ingestion/writer.py` exactly. Task 4 step 2's canonical-ref policy reproduces `KnowledgeSync._canonical_ref`. Every collaborator and setting Task 5 names (`get_settings`, `create_pool(settings.postgres_dsn)`, `OllamaEmbedder(ollama_url, embed_model, ollama_api_key)`, `PgEpisodicStore`, `AiFactorySourceStrategy`, `GitCommitCollector`, `LinkedChangeResolver`, `GitHubAppAuth`/`clone_source`/`RepoMirror`, `settings.canonical_refs`) exists in `src/main.py`'s lifespan and/or `scripts/backfill.py`; all config fields (`postgres_dsn`, `ollama_url`, `embed_model`, `ollama_api_key`, `canonical_refs`, `mirror_root`, `github_org_logins`, `github_app_id`, `github_app_private_key_path`) are present in `src/core/config.py`. `AiFactorySourceStrategy` / `roadmap_paths()` are public.
