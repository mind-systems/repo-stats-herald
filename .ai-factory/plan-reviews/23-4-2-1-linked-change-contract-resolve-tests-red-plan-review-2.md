- Affects: 4.2.2 (`.ai-factory/specs/11-linked-change-resolver.md`) — The `SourceStrategy` ABC exposes only `selects(path) -> bool`; it cannot *return* or *enumerate* a roadmap path. So specs 11/45's "roadmap path from the source strategy, not hardcoded" is realizable in 4.2.2 only by the resolver holding a candidate roadmap-filename list (`ROADMAP.md`, `.ai-factory/ROADMAP.md`) and existence-checking each against the tree at the ref while the strategy confirms selection — the filenames are not supplied by the strategy. Task 3's source-strategy test (roadmap at `.ai-factory/ROADMAP.md`, assert captured) correctly catches the concrete hardcoded-root defect it targets, but with this interface it cannot prove the injected strategy *object* is consulted; a resolver with a hardcoded two-path list would also pass. The plan already carries this observation (line 48); it does not block the current red-test/contract task since `resolve` is a stub. 4.2.2 should either interpret the "not hardcoded" guard against what the interface can provide, or add a path-yielding method to `SourceStrategy`.
- Affects: 4.2.2 and later real-roadmap consumers — The plan scopes the done-marker key to lines carrying a leading `N.N.N` identifier and declares "a line lacking an `N.N.N` identifier is not a keyable done-marker (out of scope for this milestone's roadmap shape)." This is the right contract for the Phase-4 fixtures (which are numbered), and spec 11 permits keying by "text/identifier." But note this repo's own ROADMAP.md still carries many name-only `[x]` lines (`- [x] **Project scaffold**`, `- [x] **Settings layer**`, `- [x] **commits/ feature**`), and arbitrary target repos may not use `N.N.N` at all — so an identifier-only key would silently drop such completions from `completed_tasks` when 4.2.2 runs against non-numbered roadmaps. Not a defect in this red-test/contract task (its fixtures legitimately use numbered lines); flagged so 4.2.2 (or a later source-strategy/roadmap-shape task) can decide whether to broaden the key or add a name-keyed fallback for non-`N.N.N` roadmap shapes.
